Report a Site or Telemetry Issue

Encountered a bug on the leaderboard, a glitch with server status polling, or a layout problem? You can submit an issue directly to our GitHub repository tracking board.

When submitting an issue, please try to include:

  • Description: What happened or what is not working as expected.
  • Steps to Reproduce: How can we replicate the bug on our end?
  • Screenshots / Error Logs: If applicable, attach a screenshot or paste console error details.
