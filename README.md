# BCHQ HUB

**BCHQ** is an independent Assetto Corsa Competizione (ACC) sim racing community. **BCHQ HUB** is the community's website: live server status, live session timing, lap-time leaderboards, race results and driver stats.

## What BCHQ HUB does

- **Live servers:** status, track, session countdown, weather and driver counts for each BCHQ ACC server.
- **Live timing:** a live leaderboard for each running session.
- **Leaderboards:** persistent best-lap records by track, car and session type.
- **Race results & history:** classified results for finished races, with filters by track and driver.
- **Driver profiles:** lap records, race stats, finishing positions, points and a safety rating.
- **Championship & community stats:** monthly and all-time points tables, drivers in form, cleanest drivers, popular and successful cars, and when the community races.
- **Stream overlays:** a free transparent live-timing overlay for OBS.
- **Install as an app:** works as an installable web app on phones.

## How it works

BCHQ HUB is a static website (HTML, CSS and JavaScript) served from this repository. It reads live data from a small serverless API, which stores lap times and race results from the community's dedicated ACC servers. Race and qualifying result files from the servers are uploaded automatically when each session ends.

This repository holds the public website. Server configuration, credentials and API keys are never stored here.
