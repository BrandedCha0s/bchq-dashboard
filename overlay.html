LIVE TIMING FOR OBS

1. CHOOSE YOUR OVERLAY

2. COPY THE LINK

  1. In OBS add a Browser source and paste the link as the URL.
  2. Set the width to about 600 and the height to about 500 (more rows need more height).
  3. The background is transparent, so only the timing table shows over your game.
